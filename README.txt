BUDOWANIE PRZEZ GITHUB
1. Zaloz NOWE repo na github.com i wrzuc do niego cala zawartosc tego folderu (foldery versions i .github oraz pliki .gitignore, README.txt).
2. Zakladka Actions -> przebieg "build" -> poczekaj az sie skonczy.
3. Na dole strony przebiegu w "Artifacts" sa osobne paczki: xMIBRadar-1.20.1, xMIBRadar-1.21.4, xMIBRadar-1.21.5, xMIBRadar-1.21.11.
   W kazdej jest plik xMIBRadar-1.0.0.jar.
